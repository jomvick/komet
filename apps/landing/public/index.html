Cross-device

Every session, on every device

Start an agent on one machine. Open the same session on another device and continue. Transcripts, diffs and approvals sync live.

Your harnesses

The tools you use, streamlined

Komet is not a new harness. It runs the harnesses you already use each day — Claude Code, Codex and more — in one fast window.

Lightweight

Quick on slow networks

Komet sends only small sync updates over the wire. Remote sessions stay quick on weak connections — even on plane Wi-Fi.

Native

A fast, native client

The engine is pure Rust. The app is GPU-rendered, with no browser wrapper. It is a quick window over every agent you run.
