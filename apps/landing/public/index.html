One window

Every machine, one place

Each device runs a small engine that keeps your sessions in sync. Laptop, desktop, VPS, phone — the same sessions everywhere, live.

Live sync

Start here, drive from there

Kick off an agent on one machine, then follow and steer it from another. Transcripts, diffs and approvals stream as they happen.

Always on

Close the laptop, keep working

Run the engine as a daemon on an always-on box — a VPS, a spare machine — and your agents keep running after you walk away.

Native

A fast, native client

Pure Rust engine and a GPU-rendered desktop app. No browser wrapper — just a quick window over every agent you run.

Bring your agents together.
